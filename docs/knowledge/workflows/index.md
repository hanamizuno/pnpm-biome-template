# Workflows

* [lint](lint.md) - Biome ci + 型チェック + secret スキャン (push / PR)。
* [test](test.md) - vitest 実行 + PR にカバレッジコメント (push / PR)。
* [security](security.md) - 依存関係のセキュリティ監査 (毎日)。
* [lint-gha](lint-gha.md) - GitHub Actions 自体の zizmor によるセキュリティリント。
* [deps-update](deps-update.md) - 依存関係の自動更新 PR (毎週月曜)。
* [labels](labels.md) - `.github/labels.yml` からリポジトリラベルを同期。
* [copilot-setup-steps](copilot-setup-steps.md) - GitHub Copilot 用の環境セットアップ。
