# Subdirectories

* [tools](tools/index.md) - 本テンプレートで採用しているツールチェーン (Biome / vitest / pnpm / TypeScript)。
* [workflows](workflows/index.md) - `.github/workflows` 配下の GitHub Actions ワークフロー。
* [container](container/index.md) - Dockerfile / Compose / Dev Container を中心とした実行環境。

このバンドルは [Open Knowledge Format (OKF) v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog/tree/main/okf) に準拠する。各 `.md` ファイルは YAML フロントマターで `type` を必須とし、人間と LLM/エージェント双方が読めるキュレーション知識として配置している。
